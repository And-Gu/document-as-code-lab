# Project Control Center: The Repository at a Glance

This project is both a tutorial and a working example of document-as-code. As we develop its chapters, tools, and publishing workflows, the repository also provides data that helps us follow the work.

The **[Project Control Center](https://and-gu.github.io/document-as-code-lab/dashboard/)** brings that information together on a standalone web page.

## Follow the Work

The dashboard shows open issues, proposed changes, recent commits, and workflow results. These views help answer practical questions: What needs attention? What has changed? Did the automated checks pass?

The information is collected when the website is published, with additional updates scheduled hourly. Each snapshot shows when it was generated. Scheduled runs can be delayed. It is a recorded view of the repository, not a live feed.

## Explore the Project's Growth

Interactive charts show how the project has developed through its recorded history. You can compare revisions and switch between chapter count, word count, and completed capabilities.

These measures describe growth, not quality. More words do not necessarily mean a better tutorial, and a completed capability needs verification, not merely an entry in a list.

## One Source, Different Views

The dashboard illustrates how repository information can support more than a traditional document. The same working environment provides readable chapters, interactive views, and automated publishing.

This chapter remains readable as Markdown. The linked dashboard adds the interactive experience without storing its results in the chapter itself.
