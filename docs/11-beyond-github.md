# Beyond GitHub: OneDrive, Copilot, and Other Applications


## Learning Goal

Carry the practices into environments where GitHub is not central.

## Planned Topics

- Portable content, metadata, and context packages
- A lightweight workflow using shared folders and OneDrive
- Word-based authoring and review
- Copilot with curated source material
- Version history, access, and source-of-truth conventions
- Manual export steps and automation tradeoffs
- Verify product-specific capabilities and account requirements

## Planned Exercise

Design a smaller OneDrive and Copilot workflow, with a source folder, change record, and reusable context package.

## Completion Criteria

The chapter explains the planned topics, includes a reproducible exercise, and documents relevant limitations. Product-specific behavior must be verified when the chapter is drafted.
