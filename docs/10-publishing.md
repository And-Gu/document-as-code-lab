# Publishing to Websites, Books, and Presentations


## Learning Goal

Adapt shared content to different reading and presentation contexts.

## Planned Topics

- Website navigation and search
- Assembling multiple source files into a document, with explicit selection and reading order
- Choosing content for each audience and deciding whether drafts belong in a review copy or must be excluded from a release
- PDF book structure and typography
- PowerPoint decks for different audiences
- Word and PowerPoint as editing and delivery tools
- Feeding edits in generated documents back into the source
- Shared visuals with format-specific rendering
- Recording the source revision, selected inputs, and build settings for each output
- Reviewing the assembled publication, even when its individual items have been approved

## Planned Exercise

Extend chapter 1's onboarding assembly into a web page, a PDF handbook excerpt, and a short presentation. Define the source selection and order for each audience. Label any output containing drafts as a review copy, and record which source versions produced it. Treat the fictional approval fields as teaching data, not permission to use the instructions operationally.

Expected result: three audience-specific outputs with traceable inputs and a documented publication check. Change the access procedure once, rebuild the affected outputs, and verify both the reused wording and each format's presentation.

## Completion Criteria

The chapter explains the planned topics, includes a reproducible exercise, and documents relevant limitations. Product-specific behavior must be verified when the chapter is drafted.
